Akıllı Kampüs Uygulaması

Bu proje üniversite kampüsü içerisinde öğrencilerin ve personelin
karşılaştığı sorunları bildirebilmesini ve yönetim tarafından
takip edilmesini amaçlayan bir Android uygulamasıdır.

Proje Amacı
Kampüs içindeki sorunların hızlı şekilde bildirilmesi
Bildirimlerin harita üzerinde görüntülenmesi
Admin tarafından durum takibi ve yönetimi
Kullanıcıların bildirimleri takip edebilmesi

Kullanıcı Roller:
User (Kullanıcı):
Bildirim oluşturabilir
Bildirimleri takip edebilir
Durum değişikliklerinden bildirim alır

Admin (Yönetici):
Tüm bildirimleri görür
Bildirim durumlarını günceller
Yanlış / uygunsuz bildirimleri sonlandırabilir
Acil duyuru yayınlayabilir

Harita Özelliği
Google Maps API kullanılmadan
Kampüs haritası görseli üzerinden
Konum seçimi ve pin gösterimi yapılmıştır

Bildirim Sistemi
Durum değişikliklerinde kullanıcıya bildirim
Acil durumlar için yüksek öncelikli bildirimler

Kullanılan Teknolojiler
Kotlin
Android SDK
RecyclerView
Fragment yapısı
Notification API
Git & GitHub
